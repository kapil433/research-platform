# Paper 01: Vahan Network Analysis

## Title

Structural Evolution of India's Passenger Vehicle Market: A Network Science Perspective Using VAHAN Registration Data (2015–2025)

## Abstract

_[Draft abstract — to be refined]_

This paper applies network science methods to analyze the structural evolution of India's passenger vehicle market using monthly registration data from the VAHAN portal (2015–2025). We construct a bipartite network where nodes represent OEMs and Indian states, and weighted edges represent vehicle registrations. Using Louvain community detection and temporal graph analysis, we identify how market structure shifted across three major disruptions: the BSVI emission norm transition (April 2020), the COVID-19 pandemic (2020–21), and the EV policy push (2022–present).

# Vahan Vehicle Registration Dataset

Public vehicle registration data extracted from the Vahan portal (MoRTH).

## Dataset Description

| Field | Description |
|-------|-------------|
| state | State/UT code |
| rto | RTO office |
| year | Registration year |
| month | Registration month |
| maker | Vehicle manufacturer |
| model | Vehicle model |
| fuel | Fuel type |
| category | Vehicle category |
| count | Number registered |

## Coverage

- Period: 2017 onwards
- States: All 36 states/UTs
- Vehicle Types: 2W, 3W, LMV, HMV

## Source

Vahan Dashboard: https://vahan.parivahan.gov.in/vahan4dashboard/
Ministry of Road Transport and Highways (MoRTH)
